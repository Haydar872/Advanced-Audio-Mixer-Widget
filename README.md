# 🎧 مدير الصوتيات المتقدم والأوضاع الذكية (Advanced Audio Mixer Widget)

تطبيق مصغر، عائم، وثابت (Widget) مصمم خصيصاً لنظام Windows يتيح للمستخدمين إنشاء أوضاع صوتية مسبقة الإعداد (Presets) مثل (وضع الدراسة، وضع الألعاب، وضع الأفلام) وتغيير نسبة صوت النظام الإجمالية فوراً وبنقرة زر واحدة.

## ✨ المميزات (Features)
- **واجهة مستخدم عصرية:** تصميم مظلم متناسق (Dark Mode) شبه شفاف يستقر بثبات تام على يمين الشاشة.
- **أزرار الأوضاع الذكية:** إمكانية صناعة أزرار مخصصة تحمل اسم الوضع ودرجة الصوت المفضلة له (مثال: الدراسة 20%).
- **حفظ حي وديناميكي:** يتم جلب الأزرار وإضافة الجديد منها وحذفها مباشرة عبر التزامن مع ملف `data.json` محلي.
- **تأثير أحجار الدومينو:** خاصية الحذف الفوري (✕) التي تمسح الزر من الملف وتعيد رص الأزرار المتبقية تلقائياً للأعلى لملء الفراغ.
- **تحكم حقيقي بالنظام:** ربط الأزرار برمز التحكم الصوتي لنظام Windows لتعديل شدة الصوت الحقيقية فوراً عند "فقس" الزر.

## 🚀 متطلبات التشغيل (Requirements)
يعتمد التطبيق في التحكم بالصوت على أداة `nircmd.exe` الخفيفة والمدمجة بجانب ملف الكود لضمان العمل المستقر بدون مكاتب معقدة.

## 💻 طريقة التشغيل (How to run)
قم بتشغيل الكود مباشرة عبر بيئة بايثون، أو قم بتشغيل ملف الـ `(.exe)` المصدّر.
